## 🔧 Backend APIs Being Used

### 1. POST /api/identify
- **Input**: Image file
- **API**: Google Gemini Vision
- **Output**: Object identification (species, category, confidence)

### 2. POST /api/profile
- **Input**: Identification + voice style
- **APIs**: AI personality generation + ElevenLabs Voice Design
- **Output**: Complete profile (name, traits, backstory, voice_id)

### 3. WebSocket /ws/conversation
- **Input**: Text messages
- **API**: ElevenLabs Conversational AI
- **Output**: Real-time responses

### 4. POST /api/sing
- **Input**: Name, personality, voice_id
- **API**: ElevenLabs Music API
- **Output**: Song with lyrics and audio

### 5. POST /api/ambient
- **Input**: Object category
- **API**: ElevenLabs Sound Effects
- **Output**: Ambient audio

## 🚀 Quick Start Commands

### Start Frontend (if not running)
```bash
cd frontend
npm run dev
```

### Start Backend (if not running)
```bash
cd backend
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### View API Documentation
Open http://localhost:8000/docs

### Run Backend Tests
```bash
cd backend
pytest
```
